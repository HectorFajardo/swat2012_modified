# SWAT2012

**Soil & Water Assessment Tool** — Fortran source code for the SWAT hydrological model, maintained by the Blackland Grassland Models group.

## Overview

SWAT (Soil and Water Assessment Tool) is a river basin–scale model developed to quantify the impact of land management practices on water, sediment, and agricultural chemical yields in large, complex watersheds with varying soils, land use, and management conditions over long periods of time.

This repository contains the SWAT source code, written primarily in Fortran 77/90. We intend to keep the code for archival and bugfix purposes but we are not planning to introduce new features.
